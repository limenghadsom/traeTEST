## Sudoku

A dependency-free Sudoku game in a single file: open [index.html](index.html) in a browser, or enable GitHub Pages for this repository and play it online.

Features: unique-solution puzzle generator, Easy/Medium/Hard levels, pencil notes, hints, undo, mistake counter, timer, and keyboard controls (1–9, arrow keys, N for notes, Backspace to erase).
